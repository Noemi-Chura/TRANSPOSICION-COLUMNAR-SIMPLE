APLICACIÓN WEB - TRANSPOSICIÓN COLUMNAR SIMPLE

REQUISITOS: Navegador web (Google Chrome, Microsoft Edge, Firefox, etc.).

ARCHIVOS:

- index.html → Estructura de la aplicación.
- script.js → Código para cifrar y descifrar.
- style.css → Estilos de la aplicación.

CÓMO EJECUTAR
- Abrir la carpeta del proyecto.
- Hacer doble clic en el archivo "index.html".
- La aplicación se abrirá automáticamente en el navegador.

CÓMO USAR

PARA CIFRAR:
- Ingresar el texto.
- Ingresar una clave.
- Presionar el botón "Cifrar".
- El resultado aparecerá en el campo "Resultado".

PARA DESCIFRAR:
- Ingresar el texto cifrado.
- Ingresar la misma clave utilizada para cifrar.
- Ingresar la longitud original del texto.
- Presionar el botón "Descifrar".
- El resultado aparecerá en el campo "Resultado".
