APLICATIVO DE ESCRITORIO - TRANSPOSICIÓN COLUMNAR SIMPLE
==========================================================

Requisitos: Java JDK 11 o superior instalado en tu computadora.

CÓMO EJECUTARLO
----------------
1. Abre una terminal (cmd / PowerShell / terminal de Linux o Mac)
   dentro de esta carpeta.

2. Compila el proyecto:
   javac -d bin src/*.java

3. Ejecuta el programa:
cd "d:\aplicativo-escritorio-transposicion"
javac -encoding UTF-8 -d bin src\*.java
java -cp bin AplicativoEscritorio

   Se abrirá una ventana con:
     - Un campo para el Texto
     - Un campo para la Clave
     - Botones: Cifrar / Descifrar / Limpiar
     - Un cuadro de Resultado

Opcional es abrir el EJECUTABLE:
:\aplicativo-escritorio-transposicion\app\TransposicionColumnar\TransposicionColumnar.exe
